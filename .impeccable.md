# proxy-api · Design Context

## Target audience

- **Phase 0/1**: Dylan + a small trusted "carpool" group (developers / power users)
- **Phase 2**: Public — developers who want self-hosted Claude API access through aggregated upstreams (official keys, third-party relays, IDE-subscription scrapes)

The audience is technical: they read CLI output, understand HTTP, run their own infra. They are NOT consumer end-users.

## Use cases

- Hand out / rotate API keys to clients (Claude Code, custom apps)
- Wire upstream pools (Anthropic official keys, Antigravity OAuth, Cursor session tokens)
- Monitor token spend, request volume, latency per upstream
- Manage carpool groups (isolation between Anthropic-direct and Antigravity-Claude)
- One-page fast read: "is everything healthy and how much have we burned today"

## Brand personality / tone

- **Black & white minimalist.** Refined, not flashy.
- Aesthetic lineage: **Linear, Vercel, Raycast, Anthropic Console** — restrained, dense, type-driven, no decorative gradients.
- Restraint = premium. The product is "set up and forget"; the UI should feel calm, fast, monospace-friendly.
- No teal / cyan / purple gradients (sub2api upstream's default look — explicitly being replaced).
- Hairline 1px borders preferred over drop shadows.
- Tabular numerals everywhere (this is a metrics product).
- Dark mode required from day one.

## Voice in copy

- Direct, technical, low-fat.
- English-first labels with Chinese fallback; numbers and units always in Latin.
- No exclamation marks, no emoji in product copy.
- Error states tell you what to do, not just what broke.

## Hard "do not"

- No `bg-mesh-gradient`, no colorful blur orbs, no `bg-gradient-to-br from-X to-Y`.
- No oversized rounded squircles for icons (the templated AI look).
- No big primary buttons everywhere — most actions should be ghost or text-only.
- No glassmorphism on dashboards.
- No emoji as icons (use lucide / heroicons).
